# GameMaths

Site pédagogique de mathématiques pour collégiens (11-15 ans) : un parcours
d'apprentissage des fractions, organisé en graphe de notions où maîtriser une
notion débloque les suivantes. Sans compte : la progression reste sur
l'appareil de l'apprenant.

## État du projet

**Phase de spécification.** Aucun code applicatif n'est écrit tant que la
documentation n'est pas complète et testable. Les exigences sont rédigées en
Gherkin et deviendront plus tard les tests d'acceptation.
